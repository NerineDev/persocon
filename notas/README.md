# Notas del proyecto

Documentación adicional, decisiones de diseño y apuntes relevantes durante la evolución del proyecto.

## Documentos

- `decisiones.md`: decisiones técnicas y de alcance consolidadas durante el TFG/MVP.
- `backlog.md`: backlog histórico del MVP y pendientes detectados durante el desarrollo académico.
- `roadmap.md`: roadmap histórico del Proyecto Integrado hasta su entrega.
- `changelog.md`: cambios documentales/funcionales registrados durante el desarrollo.
- `producto-post-tfg.md`: nueva fuente de verdad para la evolución del producto después del TFG, incluyendo visión, auditoría funcional/UX, arquitectura de información y alcance deseado antes de comercialización.

> Los documentos históricos del TFG se conservan para no reescribir retrospectivamente qué estaba implementado en la entrega. Para decisiones de producto posteriores al TFG, consultar primero `producto-post-tfg.md`.
